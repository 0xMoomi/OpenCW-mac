# OpenCW Mac 버전

> 이 프로젝트는 kimd0님의 [OpenCW](https://github.com/kimd0/OpenCW)를 macOS에서 쓸 수 있게 옮긴 **비공식 Mac 포트**입니다.
> 원작과 마찬가지로 [GPL-3.0-or-later](LICENSE) 라이선스를 따릅니다.
> Windows를 쓰신다면 원본 [OpenCW (Windows 버전)](https://github.com/kimd0/OpenCW)을 사용하세요.

메이플스토리 클래식월드 Mac 버전(`MapleStory Launcher` 앱)의 게임 통신만 해외 공개 중계 서버로 우회하여 네트워크 지연을 줄여주는 프로그램입니다.
브라우저 등 게임 외 다른 프로그램의 통신에는 영향을 주지 않습니다. 스위치 하나로 켜고 끄는 Mac 앱으로 동작합니다.

## 알아 두실 점

- 개인이 만든 **비공식 도구**입니다. 넥슨 및 메이플스토리와 관련이 없으며, 게임사의 승인이나 보증을 받지 않았습니다.
- 중계 서버는 인터넷에 공개된 **제3자 서버**입니다. 서버 상태는 수시로 바뀌므로 속도나 안정성을 보장할 수 없고, 표시되는 핑은 참고용입니다.
- 네트워크 경로를 바꾸는 프로그램에 대한 **게임사의 정책은 바뀔 수 있으며**, 그에 따른 계정 제재 등의 위험은 사용자가 판단해야 합니다.
- 설정 파일이나 사용 기록을 저장하지 않습니다. 외부 통신은 서버 목록 수신과 연결 품질 측정에 필요한 것뿐입니다.
- 이 프로그램은 별도의 보증 없이 있는 그대로 제공되며, 사용으로 생긴 결과에 대해 개발자는 책임지지 않습니다.

### 보안 관련

- 게임 통신은 운영자를 알 수 없는 공개 중계 서버를 거칩니다. 서버 운영자는 접속 정보(어디로 얼마나 통신하는지)와 게임 패킷을 볼 수 있습니다. 로그인은 HTTPS로 암호화되어 전달됩니다.
- 넥슨 계정에 **2단계 인증**을 켜 두세요.
- 넥슨 계정 암호를 다른 사이트와 **같이 쓰지 마세요**.

## 필요한 것

- Apple silicon(M1 이후) 또는 Intel 프로세서의 Mac, macOS 13(Ventura) 이상
- 공식 메이플스토리 Mac 런처(`MapleStory Launcher`)가 **응용 프로그램(/Applications) 폴더**에 설치되어 있어야 합니다.

## 설치하기 (처음 한 번만)

1. [Releases](../../releases/latest) 페이지에서 `OpenCW-<버전>-macos.pkg` 파일을 내려받습니다.
2. 내려받은 `.pkg` 파일을 더블클릭합니다.
3. "Apple은 악성 코드가 없는지 확인할 수 없습니다" 같은 경고가 나오면 **완료**(또는 확인)를 누르고:
   1. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
   2. 아래쪽 보안 항목의 "OpenCW-...pkg이(가) 차단되었습니다" 옆 **그래도 열기**를 누르고, Mac 로그인 암호를 입력합니다.
   3. 다시 열린 설치 창에서 **열기**를 누릅니다.
4. 설치 프로그램 안내에 따라 **계속 → 설치**를 누르고, Mac 로그인 암호를 입력합니다. 암호는 **설치할 때 이 한 번만** 묻습니다.
5. "설치가 완료되었습니다"가 나오면 끝입니다. 응용 프로그램 폴더에 **OpenCW**가 생깁니다.
6. 화면 오른쪽 위에 **"백그라운드 항목 추가됨"** 알림이 뜰 수 있습니다. OpenCW의 도우미 프로그램이 등록됐다는 뜻이니 그대로 두면 됩니다.

새 버전으로 업데이트할 때는 먼저 메뉴 막대의 단풍잎 아이콘 → **OpenCW 종료**로 앱을 끈 다음, 새 `.pkg`를 같은 방법으로 설치하면 됩니다(창만 닫으면 앱은 계속 실행 중입니다).

> 경고가 나오는 이유: 이 프로그램은 유료 Apple 개발자 인증서로 서명되지 않았기 때문입니다. 파일이 진짜인지는 아래 [내려받은 파일 확인하기](#내려받은-파일-확인하기)로 검증할 수 있습니다.

## 사용하기

1. **응용 프로그램** 폴더나 **Launchpad**에서 **OpenCW**를 엽니다.
2. 창 가운데의 **스위치**를 누릅니다. 스위치가 주황색으로 바뀌고 `연결 중`이 표시됩니다.
3. `연결됨`이 나올 때까지 기다립니다. 보통 몇 초 걸립니다.
4. 그다음 **MapleStory Launcher**를 실행해 평소처럼 게임을 시작합니다.
5. 게임하는 동안 OpenCW는 **종료하지 말고** 그대로 둡니다. 창은 닫아도 됩니다. 창을 닫으면 OpenCW는 화면 맨 위 메뉴 막대의 **단풍잎 아이콘**으로 들어가고(Dock 아이콘도 사라집니다) **연결은 그대로 유지**됩니다. 연결된 동안 아이콘 옆에 현재 핑(예: `145ms`)이 표시됩니다.
6. 창을 다시 보려면 메뉴 막대의 단풍잎 아이콘을 눌러 **OpenCW 열기**를 고르거나, 응용 프로그램 폴더에서 OpenCW를 다시 엽니다. 아이콘 메뉴에서 바로 **연결 / 연결 해제**, **서버 변경**도 할 수 있습니다.
7. 끝낼 때는 스위치를 다시 누르거나, 단풍잎 아이콘 메뉴의 **OpenCW 종료**(창이 앞에 있을 때는 Cmd+Q)로 OpenCW를 종료합니다. **OpenCW를 종료하면 연결도 해제**되고, 네트워크 설정은 자동으로 원래대로 돌아옵니다.

> 메뉴 막대가 꽉 차면 macOS가 일부 아이콘을 숨길 수 있습니다. 단풍잎 아이콘이 보이지 않으면 응용 프로그램 폴더에서 OpenCW를 다시 열어 창을 띄우세요.

화면의 **핑(ms)** 은 연결된 동안 몇 초마다 새로 잰 값입니다. 중계 서버를 거쳐 메이플스토리 로그인 서버가 있는 미국 서부(오리건) 데이터센터까지 다녀오는 시간이라, 게임 안의 핑과 조금 다를 수 있습니다. 이 측정이 잠시 안 되면 중계 서버까지의 핑을 대신 보여주고 `중계 서버까지의 핑`이라고 표시합니다.

핑이 마음에 들지 않으면 연결된 상태에서 **서버 변경**을 눌러 다른 서버로 옮길 수 있습니다. 바뀐 뒤에는 `서버 변경됨 · 미국 로스앤젤레스 → 미국 댈러스 · 152 → 128 ms`처럼 어디에서 어디로 바뀌었고 핑이 어떻게 달라졌는지 창에 잠깐 보여주며, 단풍잎 아이콘 메뉴에도 마지막 변경이 남습니다. (지역 이름은 중계 서버 출구에서 가장 가까운 큰 도시입니다.)

## 문제가 생기면

- **지역 오류 등으로 게임에 접속되지 않음** → OpenCW에 `연결됨`이 **먼저** 나온 뒤에 런처를 실행해야 합니다. 런처가 이미 켜져 있었다면 런처를 **Cmd+Q로 완전히 종료**한 뒤 다시 실행하세요.
- **OpenCW 창이 도우미에 연결되지 않음** → 설치 직후라면 잠시 기다린 뒤 OpenCW를 다시 여세요. 그래도 안 되면 **시스템 설정 → 일반 → 로그인 항목**(macOS 버전에 따라 "로그인 항목 및 확장 프로그램")의 "백그라운드에서 허용" 목록에서 **OpenCW**가 켜져 있는지 확인하고, 꺼져 있었다면 켠 뒤 Mac을 재시작하세요. 그래도 안 되면 `.pkg`를 다시 설치하세요.
- **`연결 실패`** → 다른 VPN 앱을 끄고 다시 연결하세요.
- **`서버 목록 불러오기 실패`** → 인터넷 연결을 확인하세요.
- 연결 해제 중 오류가 나거나 인터넷이 이상하면 Mac을 재시작하면 원래대로 돌아옵니다.

## 삭제하기

**응용 프로그램 → 유틸리티 → 터미널**을 열고 아래 한 줄을 붙여 넣어 실행합니다(Mac 로그인 암호를 물어봅니다. 입력해도 화면에 표시되지 않는 것이 정상입니다).

~~~sh
sudo /Applications/OpenCW.app/Contents/Resources/uninstall.sh
~~~

앱, 백그라운드 도우미, 설치 기록이 모두 지워집니다. 앱만 휴지통으로 옮기면 도우미 등록이 남으니 위 방법으로 삭제하세요.

## 내려받은 파일 확인하기

배포 파일은 태그된 소스 코드로 GitHub Actions에서 직접 만들어지며, 빌드 출처 증명(attestation)이 함께 제공됩니다. [GitHub CLI](https://cli.github.com/)가 있다면:

~~~sh
gh attestation verify OpenCW-1.1.0-macos.pkg --repo 0xMoomi/OpenCW-mac
~~~

Releases의 `SHA256SUMS.txt`와 해시를 비교할 수도 있습니다.

~~~sh
shasum -a 256 OpenCW-1.1.0-macos.pkg
~~~

## 직접 빌드하기

[Go](https://go.dev/dl/)(`brew install go`)와 Xcode 또는 Command Line Tools(`xcode-select --install`, Swift 컴파일러)가 필요합니다. Go 컴파일러 버전은 `go.mod`에 적혀 있으며 빌드할 때 자동으로 맞춰집니다.

~~~sh
./package.sh 1.1.0
~~~

`dist/OpenCW-1.1.0-macos.pkg`와 `dist/SHA256SUMS.txt`가 만들어집니다.

### 동작 방식 (참고)

- Mac용 메이플스토리는 CrossOver(Wine) 위에서 돌아가서 게임과 Nexon 런처를 서로 구별할 수 없습니다. 그래서 `/Applications/MapleStory Launcher.app` 안의 프로그램이 쓰는 통신은 모두 중계하되, 80번(HTTP 다운로드)과 853번 포트만 직접 연결합니다(로그인 서버는 80번이어도 중계).
- OpenCW는 두 부분으로 되어 있습니다. 화면을 보여주는 앱(`/Applications/OpenCW.app`, SwiftUI)과, 네트워크 경로를 바꾸는 관리자(root) 권한 도우미(`OpenCW.app/Contents/Resources/opencw-mac`)입니다. 도우미는 `/Library/LaunchDaemons/io.github.0xmoomi.opencw.plist`로 등록되어 Mac이 켜질 때 시작되고, 앱이 연결될 때까지 아무 일도 하지 않습니다.
- 앱과 도우미는 `/var/run/opencw.sock`으로 통신합니다. 도우미는 연결한 프로그램이 `/Applications/OpenCW.app/Contents/MacOS/OpenCW`일 때만 받아들이고, 앱이 종료되면(비정상 종료 포함) 연결을 해제합니다. 창을 닫는 것은 종료가 아니므로 연결이 유지됩니다.
- 핑 측정: 연결된 동안 4초마다 중계 서버를 거쳐 AWS us-west-2(오리건)의 공개 상태 확인 주소 `dynamodb.us-west-2.amazonaws.com`에 작은 HTTPS 요청을 하나 보내고, 한 번 맺은 연결을 계속 재사용하여 요청을 보낸 뒤 첫 응답이 올 때까지의 시간만 잽니다(최근 5번의 중앙값). 메이플스토리 로그인 서버(`login.maplestory.nexon.net`)가 이 지역에 있지만 게임 전용 통신만 받기 때문에, 게임·로그인 서버에는 측정용 접속을 하지 않습니다.
- 앱, 도우미, 등록 파일은 모두 관리자(root) 소유로 설치되어 일반 사용자 계정으로는 수정할 수 없습니다.
