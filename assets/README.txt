OpenCW 1.0.0
========================================

메이플스토리 클래식월드의 접속 지연을 줄이기 위해 게임 통신을 해외 공개 중계 서버를 거쳐 보내는 프로그램입니다.


[사용 방법]

1. OpenCW.exe를 실행합니다. 실행 시 관리자 권한을 요구합니다. 가상 네트워크 장치를 만들기 위해 필요합니다.
2. 가운데 스위치를 클릭하면 가장 빠른 서버를 자동으로 찾아 연결합니다.
3. "연결됨"이 표시되면 게임을 실행합니다.
4. 사용을 마치면 스위치를 끄거나 창을 닫습니다. 네트워크 설정은 자동으로 복구됩니다.


[알아 두실 점]

- 이 프로그램은 개인이 만든 비공식 도구입니다.
넥슨 및 메이플스토리와 관련이 없으며, 게임사의 승인이나 보증을 받지 않았습니다.

- 중계 서버는 인터넷에 공개된 제3자 서버입니다.
서버 상태는 수시로 바뀌므로 연결 속도나 안정성을 항상 보장할 수는 없습니다.
화면에 표시되는 핑은 참고용 측정값이며 실제 게임 서버의 핑과 다를 수 있습니다.

- 게임 접속에 필요한 통신만 중계하며, 브라우저 등 다른 프로그램의 통신은 중계 서버를 거치지 않고 평소처럼 직접 연결됩니다.
로그인을 포함한 주요 통신은 암호화된 상태로 전달됩니다. 다만 공개 서버의 운영 주체는 확인할 수 없다는 점을 고려해주세요.

- 네트워크 경로를 바꾸는 프로그램에 대한 게임사의 정책은 변경될 수 있습니다.

- 설정 파일이나 사용 기록을 PC에 저장하지 않습니다.
외부와의 통신은 서버 목록 수신과 연결 품질 측정에 필요한 것뿐이며, 개인 정보 등 추가적인 데이터를 보내지 않습니다.
프로그램이 비정상 종료된 경우에만 오류 기록을 아래 위치에 저장합니다.
%LOCALAPPDATA%\OpenCW\crashes

- 드물게 네트워크 설정이 원래대로 복구되지 않을 경우 PC를 재시작해 주세요. 모두 자동으로 복원됩니다.


[면책]

이 프로그램은 별도의 보증 없이 있는 그대로 제공됩니다.
프로그램의 사용 여부와 사용 방식은 사용자가 판단하며, 사용으로 생긴 결과에 대해 개발자는 법적 책임을 지지 않습니다.


[라이선스]

이 프로그램에는 GPL 라이선스로 배포되는 구성 요소(sing-box 등)가 포함되어 있습니다.
