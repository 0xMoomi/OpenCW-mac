# OpenCW for Mac (터미널 시험판)

메이플스토리 클래식 월드 Mac 버전(`MapleStory Launcher` 앱)의 게임 통신만 해외 중계 서버로 보내 핑을 낮추는 터미널 프로그램입니다. 다른 앱의 통신은 그대로 둡니다. 화면(GUI)은 없고 터미널 창에서 실행합니다.

## 1. 준비 (처음 한 번만)

1. **터미널**을 엽니다. (Spotlight에서 `터미널` 검색)
2. Homebrew가 있다면 Go를 설치합니다.
   ```sh
   brew install go
   ```
3. 이 폴더로 이동합니다. (폴더를 터미널 창에 끌어다 놓으면 경로가 입력됩니다)
   ```sh
   cd 이_폴더_경로
   ```

## 2. 만들기 (빌드)

```sh
./build.sh
```

`dist/opencw-mac` 파일이 생기면 성공입니다. 처음에는 필요한 파일을 내려받느라 몇 분 걸릴 수 있습니다.

## 3. 실행

1. 터미널에서 다음을 입력합니다. Mac 로그인 암호를 물어보면 입력하세요(입력해도 화면에 표시되지 않는 것이 정상입니다).
   ```sh
   sudo ./dist/opencw-mac
   ```
   네트워크 경로를 바꾸기 때문에 관리자 권한(`sudo`)이 꼭 필요합니다.
2. `연결됨: 서버 ... (핑 ...)` 이 보일 때까지 기다립니다. 보통 몇 초 걸립니다.
3. 그다음 **MapleStory Launcher**를 실행해 평소처럼 게임을 시작합니다.
   - 이미 게임이 켜져 있었다면 게임을 껐다가 다시 켜는 것이 좋습니다.
4. 게임하는 동안 터미널 창은 **닫지 말고** 그대로 둡니다.

## 4. 끝내기

터미널 창을 클릭하고 **Ctrl+C** 를 누릅니다. `연결을 해제했습니다` 가 나오면 네트워크 설정이 원래대로 돌아온 것입니다.

## 문제가 생기면

- `관리자 권한이 필요합니다` → 명령 앞에 `sudo` 를 붙였는지 확인하세요.
- `가상 네트워크(TUN)를 만들지 못했습니다` → 다른 VPN 앱을 끄고 다시 실행하세요.
- `서버 목록을 불러오지 못했습니다` → 인터넷 연결을 확인하세요.
- 연결 해제 중 오류가 나거나 인터넷이 이상하면 Mac을 재시작하면 원래대로 돌아옵니다.

## 참고

- Mac에서는 게임과 Nexon 런처가 모두 같은 Wine 프로그램으로 돌아가서 서로 구별할 수 없습니다. 그래서 `MapleStory Launcher` 앱 안의 프로그램이 쓰는 통신은 모두 중계하되, 80번(HTTP 다운로드)과 853번 포트만 직접 연결합니다(로그인 서버는 80번이어도 중계).
- 충돌 보고서(crash report) 기능은 이 시험판에 없습니다. 오류는 터미널에 그대로 출력됩니다.
